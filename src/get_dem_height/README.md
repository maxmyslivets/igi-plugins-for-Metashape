# Get DEM height
Плагин Agisoft Metashape для получения высоты из ЦММ Metashape в открытом чертеже Autocad.


### Использование

#### Точки
1. Вызвать плагин через меню `ИГИ/Взаимодействие с Autocad/Получение высоты из ЦММ в Autocad/Точки`.
2. В Autocad указать точку (или несколько точек) для получения высоты в указанном месте.

#### По сетке
1. Вызвать плагин через меню `ИГИ/Взаимодействие с Autocad/Получение высоты из ЦММ в Autocad/По сетке`.
2. В появившемся окне настройки параметров указать шаг сетки, направление (опционально) и погрешности (опционально).
   1. **Расстояние между точками сетки (м)** — номинальный шаг, с которым будут расставляться точки (по умолчанию 20 м).
   2. **Учесть направление** — если необходимо указать направление, поставить галочку. При следующем запросе выбора объекта в AutoCAD необходимо будет выбрать линию, которая задаст ориентацию сетки.
   3. **Имитировать неравномерный шаг (ходьба человека)** — при установке галочки включает режим внесения случайной погрешности в расстояния между соседними точками, что позволяет имитировать реальную съёмку с неравномерным шагом оператора.
      1. **Уменьшение, %** — максимальный процент, на который может уменьшиться расстояние между соседними точками относительно номинального шага (по умолчанию 15%, т.е. для шага 20 м минимальное расстояние составит 17 м).
      2. **Увеличение, %** — максимальный процент, на который может увеличиться расстояние между соседними точками (по умолчанию 5%, т.е. для шага 20 м максимальное расстояние составит 21 м).
      > **Примечание:** расстояния контролируются отдельно для каждой строки и каждого столбца сетки. Это гарантирует, что любые две соседние точки по горизонтали или вертикали всегда находятся в допустимом диапазоне, а сама сетка приобретает естественную «волнистость», характерную для ручного обхода поля.

   **Примеры параметров погрешности:**

   | Шаг сетки | Уменьшение | Увеличение | Диапазон расстояний |
   |-----------|------------|------------|---------------------|
   | 10 м      | 10%        | 10%        | 9.0 … 11.0 м        |
   | 20 м      | 15%        | 5%         | 17.0 … 21.0 м       |
   | 50 м      | 20%        | 10%        | 40.0 … 55.0 м       |

3. В AutoCAD указать полигон, внутри которого будут создаваться отметки высот.
   1. Если было указано направление, то при следующем запросе выбора объекта необходимо выбрать линию, которая укажет направление расстановки.

#### По линии
1. Вызвать плагин через меню `ИГИ/Взаимодействие с Autocad/Получение высоты из ЦММ в Autocad/По линии`.
2. В появившемся окне настройки параметров указать шаг расстановки отметок.
   1. Если необходимо проставлять дополнительные точки между вершинами - указывается максимально допустимое расстояние между точками.
3. В Autocad указать линию, вдоль которой будут создаваться отметки высот.

Примечание: алгоритм расстановки по линии учитывает наличие дуговых элементов в полилинии.
