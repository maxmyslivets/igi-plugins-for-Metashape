# Get DEM height
Плагин Agisoft Metashape для получения высоты из ЦММ Metashape в открытом чертеже Autocad.


### Использование

#### Точки
1. Вызвать плагин через меню `ИГИ/Взаимодействие с Autocad/Получение высоты из ЦММ в Autocad/Точки`.
2. В Autocad указать точку (или несколько точек) для получения высоты в указанном месте.

#### По сетке
1. Вызвать плагин через меню `ИГИ/Взаимодействие с Autocad/Получение высоты из ЦММ в Autocad/По сетке`.
2. В появившемся окне настройки параметров указать шаг сетки и направление (если требуется).
   1. Если необходимо указать направление - поставить галочку у соответствующей настройки.
3. В Autocad указать полигон, внутри которого будут создаваться отметки высот.
   1. Если было указано направление. то при следующем запросе выбора объекта, необходимо выбрать линию, которая укажет направление расстановки

#### По линии
1. Вызвать плагин через меню `ИГИ/Взаимодействие с Autocad/Получение высоты из ЦММ в Autocad/По линии`.
2. В появившемся окне настройки параметров указать шаг расстановки отметок.
   1. Если необходимо проставлять дополнительные точки между вершинами - указывается максимально допустимое расстояние между точками.
3. В Autocad указать линию, вдоль которой будут создаваться отметки высот.

Примечание: алгоритм расстановки по линии учитывает наличие дуговых элементов в полилинии.
